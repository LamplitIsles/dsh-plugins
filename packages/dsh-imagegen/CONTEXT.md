# Image Generation

Image generation produces images from a prompt and optional reference images for
people to preview, download, and reuse in later edits.

## Language

**Target filename**:
The descriptive name an agent requests for a generated image.
_Avoid_: Output directory, image identifier

**Saved filename**:
The final name of a generated image, with a numeric suffix when needed to
distinguish it from an existing image with the requested name.

**Reference image**:
An existing image supplied with a prompt to guide an image edit.
